# Materialized Canvas

给上海交通大学 Canvas（[oc.sjtu.edu.cn](https://oc.sjtu.edu.cn)）换上 **Material Design 3** 外观。

整站重新配色、圆角化，并为常用页面重新设计布局；支持自选主色、浅色 / 深色 / 跟随系统，手机上同样可用。

## ✨ 功能

### 主题
- 由一个**种子色**动态生成整套 M3 色板（Material Color Utilities），默认交大红，也可选预设色或任意颜色
- **浅色 / 深色 / 跟随系统**三种模式，**标准 / 中 / 高**三档对比度
- 深色模式下会重新着色老师在课程页面、公告里设置的文字和背景颜色，以及富文本编辑器，避免"黑底黑字"
- 设置即时生效，无需刷新

### 全站外观
- 左侧全局导航改为 M3 **Navigation Rail**，课程菜单改为导航抽屉
- 胶囊按钮、填充式输入框、圆角卡片、对话框、标签页、表格、菜单统一为 M3 风格
- 非线性的 M3 动效：页面切换反馈与顶部进度条、列表逐行入场、按钮波纹、课程菜单展开 / 收起动画
- 遵循系统"减少动态效果"设置

### 重新设计的页面
- **控制面板**：M3 课程卡片，待办列表中的课程名在任意课程色上都清晰可读
- **作业**：药丸形搜索框、分段按钮、按类型着色的图标块；作业详情页的信息以小卡片网格呈现
- **评分**：固定表头的成绩卡片、突出显示已得分数、作业组小计与总分的色调区分、侧栏大号总分卡片
- **讨论**：分区卡片、对话图标、未读 / 总回复数标签
- **课程主页**：大纲时间表、单元列表、活动流，以及右侧的课程按钮、待办事项、最近反馈、迷你日历卡片
- **文件**：导航抽屉式文件夹树、按文件类型着色的图标块，**文件夹始终排在文件前面**
- **人员**：药丸搜索与筛选、角色标签、头像悬停效果、加载骨架屏
- **单元、测验、日历、收件箱、个人设置**等页面同样完成了配色与圆角化

### 手机适配
窄屏（< 768px）下的顶栏、导航抽屉、课程菜单和设置面板（底部抽屉）同样是 M3 外观。

## ⚙️ 设置

打开设置面板的方式：
- 左侧导航栏底部的 **「外观」** 按钮（手机上：左上角菜单 → **「外观」**）
- 或脚本管理器菜单里的 **「Materialized Canvas 设置」**

可调整主色、外观模式、对比度、深色模式下是否重新着色正文，也可以一键关闭美化、恢复 Canvas 原样。

## 🔐 权限说明

| 权限 | 用途 |
| --- | --- |
| `GM_getValue` / `GM_setValue` / `GM_deleteValue` | 保存你的设置，以及样式缓存（让页面打开时不闪烁） |
| `GM_registerMenuCommand` | 在脚本管理器菜单里加入「设置」入口 |
| `GM_xmlhttpRequest` + `@connect` | **只用于下载一次学校校徽并缓存到本地**。Canvas 的校徽链接每次都会跳转到一个无法缓存的签名地址，导致每次打开页面都要等约 3 秒；缓存后校徽立即显示。校徽所在的文件服务器域名不固定，所以声明了 `@connect *` |
| `unsafeWindow` | 把 Canvas 自带 jQuery 动画的缓动曲线换成 M3 曲线 |

> 首次加载时 Tampermonkey 可能询问是否允许访问某个文件服务器域名，这就是上面的校徽请求，选「总是允许」即可。拒绝也不影响其他功能，只是校徽加载会慢一些。

## 🛡️ 隐私

- 脚本**不收集、不上传**任何数据，没有统计、没有广告，不连接任何第三方服务器。
- 唯一的网络请求是上面提到的校徽下载（来自 Canvas 自身的资源地址）。
- 设置和样式缓存只保存在你本机的脚本管理器中。
- 脚本**只修改页面外观**，不会代你提交作业、发送消息或改动任何课程数据。

## 🧩 兼容性

- 浏览器：较新的 Chrome / Edge / Firefox / Safari（需要支持 CSS `:has()` 与 `color-mix()`，2023 年以后的版本均可）
- 脚本管理器：Tampermonkey、Violentmonkey
- 适用于学生视角；教师专用页面（如 SpeedGrader）只做了自动配色，未逐页精修

## ⚠️ 已知限制

- 课程中嵌入的**第三方工具**（LTI，如视频平台、外部测验）运行在跨域 iframe 中，浏览器不允许脚本修改，会保持原样
- Canvas 更新改版后，个别页面的样式可能需要跟进；遇到问题可在设置里一键关闭美化
- 文件页把文件夹排在前面是视觉重排，键盘 Tab 顺序仍按 Canvas 原始顺序
